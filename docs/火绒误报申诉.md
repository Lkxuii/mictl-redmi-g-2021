## 正文模板（复制即用）

> **标题：[样本误报] 自开发的开源程序 MiCtl.exe 被判 Backdoor/Steam**
>
> 火绒的文件实时监控把 .NET Framework 自带 csc.exe 编译出的自写程序 MiCtl.exe 判为 Backdoor/Steam（病毒 ID A560FE0CA8008175）并自动删除。触发时机是编译器输出文件的一瞬间，程序本身还没有运行过（安全日志里操作类型是"修改"，进程是 csc.exe）。
>
> 这个程序是我为自己的 Redmi G 2021 笔记本写的开源硬件控制台，源码完全公开：https://github.com/Lkxuii/mictl-redmi-g-2021 。功能是读取和显示 CPU / GPU 温度、风扇转速、内存、电池等信息，切换性能档位（调用笔记本固件暴露的 WMI 接口 MICommonInterface）。
>
> 两个容易触发启发式的特征说明一下：需要管理员权限是因为调用固件 WMI 接口（root\WMI 的 MiInterface 方法）要求管理员，这是 Windows 的要求；程序里有低级键盘钩子是因为界面上有"禁用 Win 键（游戏防误触）"的功能开关，由用户手动开启。
>
> 附件是样本（MiCtl.exe，版本 1.1.0.0）。麻烦复核，感谢！

## 备注

- 申诉被采纳后，火绒引擎更新会让所有用户不再误报这个报毒规则；本地开发期间已把相关文件路径加入火绒信任区，不影响日常使用。
- 每次重新编译出的 exe hash 不同；如果之后某次新编译的文件又被报，可以再提交一次，或考虑把开发目录加为火绒"文件夹及子目录"信任项。
